# WynnForge mod downloads

`wynnforge-export-1.0.0.jar` is the Fabric 1.21.11 client mod built from [`mods/wynnforge-export`](../mods/wynnforge-export). Install it alongside Fabric API for 1.21.11. See the [installation and export guide](../mods/wynnforge-export/README.md).

This directory is included in the static website build so its import dialog can offer a direct download.
